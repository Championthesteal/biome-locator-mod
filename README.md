## 📖 About

Biome Locator finds the nearest biome of any type from your current position using the world seed, displaying distance and direction in the HUD.

---

## ✨ Features
<a name="features"></a>

- **All Biomes** — search for any biome including 1.21 additions.
- **Distance & Direction** — compass-style HUD pointing to the target biome.
- **Seed-Based Search** — uses the recovered seed for precision.
- **Multi-Result** — shows top 5 nearest instances.
- **Map Marker** — pins results on the minimap.
- **Nether Biome Support** — finds Warped Forest, Soul Sand Valley, etc.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
